# UTN — Tecnicatura Universitaria en Programación

Repositorio público de apuntes y resúmenes de estudio de la Tecnicatura Universitaria en Programación.

## Materias

| Materia | Contenido |
|---|---|
| [Programación I](programacion-1/) | Algoritmos, pseudocódigo, C++ y diagramas de flujo |
| [Arquitectura y Sistemas Operativos I](arquitectura-sistemas-operativos-1/) | Hardware, arquitectura y sistemas operativos |
| [Matemática](matematica/) | Teoría, fórmulas y ejercicios resueltos |
| [Organización Empresarial](organizacion-empresarial/) | Modelos, autores y conceptos de organización |

## Organización

Cada materia se divide por unidades. Dentro de cada unidad se pueden incluir resúmenes integrales, ejercicios y material propio de estudio.

> Estos apuntes son material de estudio elaborado a partir de la cursada. No sustituyen las fuentes oficiales de la UTN.
